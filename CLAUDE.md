## Чек-лист выкладки на прод

1. `composer install --no-dev --optimize-autoloader`
2. `php artisan migrate` — добавляет `messages.deleted_at` (корзина заявок, п.8), таблицу `pages` (п.15), `main_sets.contact_form_enabled` (п.24) и таблицу `notification_settings` (п.25). **Без этого упадут страница заявок и все публичные страницы**
3. `php artisan admin:create` — если администратора ещё нет (регистрация закрыта, п.1)
4. Проверить в `.env`: `APP_DEBUG=false`, `APP_ENV=production` (п.3)
5. `php artisan view:clear && php artisan cache:clear`
6. `php artisan images:prune` → посмотреть список → `php artisan images:prune --force` (п.4)
7. В админке: «Настройки страницы» — исправить записи с меткой «не используется на сайте» (п.10)
8. В админке: «Настройки сайта» — пересохранить; если Telegram/WhatsApp в нестандартном виде, форма подскажет (п.6)
9. После выкладки п.13: открыть `https://kbr-mebel.ru/sitemap.xml` — в нём должны остаться только категории с фото; при желании переотправить sitemap в Яндекс.Вебмастер
10. До выкладки, локально: `npm run backend` — пересобрать CSS и JS (стили документов и галочки согласия, JS-проверка галочки, п.15) и выложить `public/css` и `public/js`
11. В админке: «Политика конфиденциальности» и «Согласие на обработку ПД» — вставить тексты из `docs/legal/` с заполненными реквизитами (п.15). Пока текст пустой, страницы и ссылки на неё на сайте нет
12. В админке: «Уведомления о заявках» — указать адрес и SMTP, нажать «Отправить тестовое письмо» (п.25). Удалить `TELEGRAM_*` из `.env` на сервере; отозвать токен бота в @BotFather
13. По желанию: удалить из `users` аккаунты, созданные через старую открытую регистрацию (п.1)
